# ТЗ-08 — Роли SUPERADMIN / ADMIN / OPERATOR / MANAGER и аудит

**Исполнитель:** субагент «RBAC».  
**Исходное ТЗ:** §14.  
**Зависимости:** ТЗ-01 не обязательна. Желательно знать сущности 02–09 для списка действий.  
**Блокирует:** видимость админки ТЗ-10, кнопки бота.

## Цель

Разграничение доступа ролями из ТЗ. Критические действия пишутся в audit log (механизм уже есть).

## Контекст кода

Биты `Permission` в `bot/database/models/main.py`. Сиды: `USER`, `ADMIN`, `OWNER`. Фильтры `HasPermissionFilter`. Нельзя выдать бит, которого нет у себя (`role_management`).

ТЗ-имена:

```text
SUPERADMIN  ≈ текущий OWNER (OWN + все биты)
ADMIN       ≈ текущий ADMIN + при необходимости ADMINS_MANAGE нет
OPERATOR    поддержка, заказы, ручной refund, тикеты; без ролей и без опасных настроек
MANAGER     каталог, склад, промо, поставщики; без BALANCE_MANAGE / без OWN
```

Пользователь магазина остаётся `USER` (не из списка ТЗ — это ок).

## Задача

1. Сид ролей: `SUPERADMIN`, `ADMIN`, `OPERATOR`, `MANAGER` (+ сохранить `USER`). Миграция переименования `OWNER→SUPERADMIN` или алиас в UI и оба имени в переходный период.
2. Матрица битов (зафиксировать в MEMORY). При необходимости новые биты: `ORDERS_MANAGE`, `TICKETS_MANAGE`, `PROVIDERS_MANAGE`, `PAYMENTS_CONFIG` — не сваливать всё в `USERS_MANAGE`.
3. SQLAdmin и in-chat админ: скрыть недоступное (как сейчас по битам).
4. Audit: refund, смена баланса, смена роли, правка шлюза, выдача склада, отмена заказа, ответ в тикет — `log_audit` с resource_id.
5. Не ломать тест «нельзя эскалировать права».

## Направление

- Не переходить на Casbin/внешний IAM.
- OWNER_ID из env по-прежнему полный доступ.

## Вне скоупа

Новые экраны тикетов (только биты). Смена платежной логики.

## Критерии приёмки

- [ ] Четыре роли из ТЗ создаются `Role.insert_roles()` / миграцией.
- [ ] OPERATOR не может CRUD ролей и не видит конфиг платёжных секретов.
- [ ] MANAGER может товары/склад, не может `BALANCE_MANAGE`.
- [ ] SUPERADMIN может всё, включая аудит.
- [ ] Критическое действие пишет строку `audit_log` (тест по аналогии `tests/test_audit.py`, `tests/test_role_management.py`).
- [ ] Существующие админ-хендлеры не открываются без бита.

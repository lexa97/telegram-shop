## Правила для исполнителя

1. Не переписывать платформу с нуля. Репозиторий — адаптация `interlumpen/Telegram-shop` (этот код).
2. Перед работой прочитать `docs/MEMORY.md` и этот индекс.
3. Денежные суммы — **только целые копейки (`BIGINT`)**. Запрещены `float`/`double`/`Numeric` для денег после миграции из ТЗ-01.
4. Валюта первой версии — **только RUB**.
5. Telegram-бот не должен ждать внешние HTTP-вызовы поставщиков/платежей: длительное — в worker.
6. Идемпотентность: unique constraints + транзакции + `SELECT … FOR UPDATE`.
7. Каждый PR исполнителя обязан закрывать **критерии приёмки** своего документа и не ломать чужие контракты (см. «Контракты между задачами»).
8. После кода: тесты из раздела «Приёмка» своего ТЗ, затем запись в `docs/MEMORY.md` (skill `pr-memory-graphify`).

## Контракты между задачами

Исполнители договариваются через эти имена (менять только согласованно):

- Деньги: поле `*_cents: int` (`BIGINT`), 299 ₽ = `29900`.
- Заказ: сущность `Order` + enum статусов `CREATED | PROCESSING | COMPLETED | FAILED | EXPIRED | REFUNDED`.
- Товар: `fulfillment_type`: `STOCK | API`; флаг `allows_gift`.
- Поставщик: протокол `DigitalGoodsProvider` в отдельном пакете, **не** в handlers бота.
- Платежи: `PaymentInstrument` (что видит пользователь) + `PaymentGateway` (Platega и др.) в БД.
- Реферал: начисление **с завершённого заказа**, не с пополнения (смена текущей логики).
- Вывод денег с баланса в v1 **не делать**.

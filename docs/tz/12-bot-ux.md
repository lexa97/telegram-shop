# ТЗ-11 — Telegram-бот: пользовательские сценарии

**Исполнитель:** субагент «aiogram UX».  
**Исходное ТЗ:** §2.  
**Зависимости:** сервисы ТЗ-04, 06, 07, 09. Не дублировать бизнес-логику в handlers.

## Цель

Бот: регистрация, каталог, карточка, баланс, пополнение через инструменты из БД (Platega), покупка за баланс, автовыдача, себе/подарок, промо, рефералка, история заказов (не только BoughtGoods), поддержка.

Первая версия — только RUB в текстах.

## Контекст кода

Хендлеры: `bot/handlers/user/shop_and_goods.py`, `cart.py`, `balance_and_payment.py`, `referral_system.py`, `main.py`. i18n `bot/i18n/strings.py` ru/en.

## Задача

1. Карточка товара: тип выдачи (склад/онлайн), возможность подарка, цена в ₽.
2. Покупка: подтверждение, промо, gift → запросить username/id получателя (получатель должен быть зарегистрирован в боте — иначе понятная ошибка).
3. Пополнение: список **включённых инструментов**; Platega — ссылка; не хардкодить три кнопки.
4. История: статусы заказа PROCESSING/COMPLETED/…, не сырой ключ до COMPLETED.
5. Реферальная ссылка как сейчас (`t.me/bot?start=ref`).
6. Тикеты вместо голого URL helper (helper можно оставить запасным в конфиге).
7. Не блокировать event loop на Provider HTTP (вызов оркестратора).
8. i18n: новые ключи ru+en.

## Направление

- Handlers только: парсинг callback, вызов сервиса, localize, клавиатура.
- Сохранить поиск, отзывы, restock notify — не вырезать без MEMORY.

## Вне скоупа

Mini App, смена платежного API.

## Критерии приёмки

- [ ] Сценарий: /start → категория → товар STOCK → купить → сообщение с ключом (при достаточном балансе).
- [ ] Подарок: ключ уходит получателю; покупатель видит подтверждение без ключа.
- [ ] API-товар: «заказ обрабатывается», затем (после worker) сообщение с результатом.
- [ ] Недостаточный баланс предлагает пополнение, не уходит в минус.
- [ ] Список методов пополнения совпадает с enabled в БД.
- [ ] История показывает FAILED/REFUNDED корректно.
- [ ] Тикет создаётся из меню.
- [ ] Тесты handlers обновлены (`tests/test_shop_handlers.py`, `test_user_handlers.py`, `test_payment_handlers.py`).
